# PharmaLog AI — project notes for Claude Code

ระบบบันทึกบทสนทนาเภสัชกร-ผู้ป่วย → ถอดเสียง (Typhoon) → สรุปเวชระเบียน (Groq LLM) → เก็บผล (SQLite + Firestore)
ตอบผู้ใช้เป็นภาษาไทย

## Components (macOS, Python 3.11 venv at ./venv — Python 3.13 does NOT work with NeMo)
| Port | File | Role |
|---|---|---|
| 8500 | `api.py` | Bridge API + patient consent page (`consent_app/index-popup-scenes.html`). Owns state WAITING→READY→RECORDING→FINISHED in `record/shared_state.json`, consent tables in `record/pharmalog.db` |
| 8080 | `core_api/main.py` | Upload → STT (`unified_app/modules/stt_typhoon.py`) → pharmacy dictionary → EMR (`unified_app/modules/emr_groq.py`). Tasks in `core_api/api_queue.db` |
| 8501 | `pharmacist_app.py` | Pharmacist web: records only after the patient consents |
| 8515 | `unified_app/app.py` | Back-office web: records immediately, no consent gate |
| 8525 | `lab/app.py` | Research lab (optional) |

Start everything: `./start_pharmalog.command` (reads `pharmalog.env`). Logs in `logs/`. User manual PDF is generated by `docs/make_user_manual.py`.

## Settings (env vars, also in `pharmalog.env`)
- `PHARMALOG_STT_ENGINE=whisper|realtime` — project default is **whisper** = `typhoon-ai/typhoon-whisper-large-v3` (user decision 2026-11-07; model via `PHARMALOG_WHISPER_MODEL`). It has NOT been accuracy-tested yet (8 GB Mac too small) — a friend will run `WHISPER_TEST_GUIDE.md`. `realtime` = typhoon-asr-realtime NeMo, the tested light fallback.
- `PHARMALOG_WHISPER_DEVICE=cpu|mps` (MPS was unreliable for Whisper in earlier tests)
- `PHARMALOG_DISABLE_CLOUD=1` → no Firestore/Storage writes. **ALWAYS set this when testing.**
- `PHARMALOG_CONSENT_TTL` (s, default 120), `PHARMALOG_RECORDING_MAX_S` (default 1800: stuck RECORDING → WAITING, consent 'abandoned'), `PHARMALOG_EMR_MODELS`, `PHARMALOG_EMR_DEADLINE_S`, `PHARMALOG_ROLE_RULES=0|1`, `PHARMALOG_HOST` (default 127.0.0.1)

## Tests
- `tests/stt_compare.py` → `logs/stt_compare.jsonl|md` (CER vs `ground_truth/`, resumable)
- `tests/choose_engine.py` → recommendation in `logs/stt_decision.txt`; only writes `pharmalog.env` with `--apply`
- `tests/e2e_check.py` → starts its own APIs (ports must be free), cloud disabled → `logs/e2e_report.md`, `logs/e2e_results.json`; deletes its own test tasks/e2e consents at the end (`E2E_KEEP_TASKS=1` keeps them). `/tasks` hides `source=test` unless `include_test=1`
- `run_all.command` runs the three in order.

## Rules
- Real patient audio: never upload anything to the cloud while testing; never commit/push `*.wav`, keys, `*.db`.
- Do not `git push` or commit unless the user asks. Original files before the 2026-11-07 fixes: `_backup_before_fixes_20261107/`.
- Secrets: `.groq_api_key`, `.gemini_api_key`, `core_api/serviceAccountKey.json` — never print them.
- `qwen/qwen3.8-27b` IS a valid Groq model (listed in groq SDK 1.7).

## Facts learned while testing (2026-11-07)
- This Mac: 8 GB RAM (~3.7 GB wired), disk nearly full. Whisper Large v3 (fp32 ~6 GB) is not practical here; whole-file NeMo decoding of long audio swaps the machine to death — always chunk (`audio_utils.split_on_silence`).
- Groq account (free/on_demand): only `openai/gpt-oss-120b`, `qwen/qwen3.8-27b`, `openai/gpt-oss-20b` usable (llama-3.3-70b → 404). Limits per model: 8000 TPM and **200k tokens/day**. One full `e2e_check.py` uses ~half a day's quota. gpt-oss-20b often returns empty/lazy answers (rejected by `_usable`).
- typhoon-asr-realtime spells ำ as ํ+า; `stt_typhoon._clean` normalises it.
- An old Streamlit from `~/Desktop/PJ/Pharmatalk_project` (Python 3.13, PID started Sep 12) used to listen on *:8501; closed with the user's OK on 2026-11-07. If 8501 is busy again, start_pharmalog.command now reports it.
